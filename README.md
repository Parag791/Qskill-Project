# QSkill Internship — 3 Beginner Tasks

This pack contains:
1. Task 1 — Personal Portfolio Website (HTML, CSS, JavaScript)
2. Task 2 — Online To-Do & Task Management App (Node.js + Express + JSON-file storage)
3. Task 3 — Blog Management Website (Node.js + Express + JSON-file storage)

## Task 1: Portfolio
Open `task1-portfolio/index.html` in a browser.

## Task 2: To-Do app
1. Install Node.js.
2. Open a terminal in `task2-todo`.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3001

Features: add, complete, and delete tasks. Data is saved in `data/tasks.json`.

## Task 3: Blog app
1. Open a terminal in `task3-blog`.
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3002

Features: create, edit, and delete posts. Data is saved in `data/posts.json`.

## Important
The two backend projects use a JSON file as lightweight local storage to keep setup beginner-friendly. If your evaluator specifically requires a database such as MongoDB/MySQL, replace the JSON-file storage with that database before submission. Personalize the portfolio with your own details and take screenshots of each project running.
